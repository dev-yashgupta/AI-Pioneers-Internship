# Week 01 — Submission Description

During Week 1 of the AI Pioneers Machine Learning Internship, I developed a Python-based workflow for preparing structured banking data for analysis and later machine learning tasks. The work focuses on Python fundamentals and the practical use of NumPy and Pandas to inspect, clean, transform, and understand tabular datasets.

The project is designed around the Bank Marketing dataset available through the UCI Machine Learning Repository. This dataset relates to telephone marketing campaigns conducted by a Portuguese banking institution and records whether a customer subscribed to a term deposit. The repository includes a documented data-loading script that downloads the official dataset and a Jupyter notebook that explains the preprocessing workflow step by step.

The implementation covers loading CSV data, checking dataset dimensions and data types, reviewing descriptive statistics, identifying missing values, trimming inconsistent whitespace, converting blank strings to missing values, imputing numerical fields with their median, and filling missing categorical fields with an explicit unknown category. Exact duplicate records are identified and removed, while an IQR-based report is generated to review possible numerical outliers. Outliers are not automatically deleted because extreme observations may be valid in a banking context.

I also documented a feature-selection decision for the call-duration field. Since this information is only known after a phone call has finished, it is excluded from the model-ready inputs for a pre-call prediction use case to reduce the risk of target leakage. Categorical columns are one-hot encoded, numerical columns are standardized, and a stratified training/test split is created. The preprocessing transformations are fitted on the training partition and then applied to the test partition.

The project exports a cleaned CSV, data-quality and outlier reports, EDA charts, transformed feature matrices, target files, and a JSON manifest. The code was smoke-tested using a small synthetic fixture included for offline validation; this fixture is clearly labelled and is not represented as real customer information or as the UCI dataset. The official UCI dataset can be processed by running the documented download and pipeline commands. This task strengthened my understanding of data quality, feature preparation, exploratory analysis, and reproducible preprocessing practices.
